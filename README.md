# Portfolio site

A minimal React + TypeScript (TSX) app powered by Vite, with Oxlint for linting.

## Getting started

Requires Node.js 22.12+ or a newer supported LTS release and npm.

```sh
npm install
npm run dev
```

Open the local URL printed in your terminal.

## Commands

- `npm run dev` starts the development server with hot reload.
- `npm run build` checks TypeScript and builds the site into `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` checks the source with Oxlint.

## Where to work

- `src/App.tsx` contains the main page.
- `src/App.css` contains page styles.
- `src/index.css` contains global styles.
- `public/` holds static files served directly.
- `index.html` contains the page title and metadata.

Built from the official [Vite React TypeScript starter](https://vite.dev/guide/).
